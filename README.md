# ElevatorHypergraph
Constraint hypergraph system model for a vertical elevator. The PDF shows the visual graph, while the Python code simulates the system. 

Note that running the code requires the package `ConstraintHg` to be loaded (`pip install constrainthg`). More information on the library can be found here: [https://github.com/jmorris335/ConstraintHg](https://github.com/jmorris335/ConstraintHg)
